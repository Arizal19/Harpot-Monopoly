Taruh model 3D karakter (format .glb) di folder ini dengan nama sesuai id karakter:
deya.glb, albus.glb, voldemort.glb, snape.glb, minerva.glb, bellatrix.glb, draco.glb, ron.glb,
remus.glb, sirius.glb, tonks.glb, gilderoy.glb, dolores.glb

Aktifkan dengan menambahkan <script>window.HARPOT_GLB=true</script> sebelum js/view.js.
Bila file ada, game memakainya sebagai pion (tinggi dinormalkan otomatis, telapak kaki di petak).
Bila tidak ada atau tidak diaktifkan, game memakai miniatur bergaya bidak catur yang dibuat otomatis.
